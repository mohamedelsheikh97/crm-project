Example Company — a page we do not control

Chat widget host page

This page exists to prove the widget survives a foreign host: its own reset, its own serif typography, and a sticky header at z-index: 9999.

Switch data-locale to ar below and reload. The widget must render right-to-left even though this document is dir="ltr" — its direction comes from its own configuration, never from the host (FR-076).

Build the bundle with npm run build:widget --workspace frontend, then serve this page from the same origin as the built asset.
